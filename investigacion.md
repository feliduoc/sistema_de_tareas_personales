# Investigación Complementaria  Git y GitHub

### ¿Qué es Git?
R:Git es un sistema de control de versiones distribuido, lo que significa que un clon local del proyecto es un repositorio de control de versiones completo. Estos repositorios locales totalmente funcionales facilitan el trabajo sin conexión o de forma remota

### ¿Qué es GitHub?
R: es una plataforma para git, para compartir proyecto, almacenar y trabajar junto con otros usuarios

### ¿Cuál es la diferencia entre Git y GitHub?
R:Git es para el contro del versiones, mientras que github es para trabajo tanto en slitario o colaborativo

### ¿Qué es un repositorio?
R:resumidamente es una caja donde mantienes tus cosas ordenadas y documentada cada vez que sufre un cambio 

### ¿Qué función cumple git add?
R: por lo que busque en internet, el git add tiene la funcion de añadir contenido del directorio de trabajo al área de ensayo (staging area o 'index') para la próxima confirmación
### ¿Qué función cumple git commit?
R: registrar a traves de mensajes las modificaciones/actualizaciones del repositorio 

### ¿Qué función cumple git push?
R: subir tus confirmaciones (commits) desde tu repositorio local hacia un repositorio remoto

### ¿Qué función cumple git pull?
R: el comando se usa para actualizar tu repositorio local de manera remota

### ¿Cuáles son las ventajas del control de versiones?
R: 1.permiten localizar cada cambios realizado en el codigo o archivo
   2.Da la seguridad de poder volver a una versión antigua y funcional si el programa actual falla
